FRONTEND-BACKEND CONNECTION SUMMARY
====================================

The application now uses the intended MERN + REST architecture.

Architecture:
  React frontend
       |
       | REST / JSON
       v
  Express backend
       |
       | Mongoose
       v
  MongoDB

Current frontend connection:
  - `frontend/src/lib/apiClient.ts` is the shared Axios REST client.
  - Authentication uses HttpOnly JWT cookies.
  - Contact, QuickEnquiry and GetInvolved submit through REST endpoints.
  - Admin pages use the REST service modules for their supported operations.

Current backend connection:
  - Public and authenticated APIs are mounted under `/api`.
  - `POST /api/enquiries` persists enquiries to MongoDB.
  - Admin volunteer operations are under `/api/admin/volunteers`.
  - Authentication is provided by `/api/auth/*`.

Removed legacy architecture:
  - GraphQL endpoint
  - GraphQL client
  - GraphQL resolver/type-definition tree
  - Obsolete GraphQL dependency lockfile

Local smoke test:
  1. Configure `backend/.env` from `backend/.env.example`.
  2. Start MongoDB or configure MongoDB Atlas.
  3. Run `cd backend && npm run dev`.
  4. Run `cd frontend && npm run dev`.
  5. Submit an enquiry from the frontend and verify the saved MongoDB document.

Production note:
  End-to-end production verification still requires the real MongoDB, SMTP, payment gateway, frontend URL, backend URL, HTTPS and CORS/cookie configuration.
