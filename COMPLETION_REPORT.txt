beneficiaries, projects, events, internships, messages, receipts, donations,
news, campaigns and reports.

  frontend/src/lib/apiClient.ts

================================================================================
SECURITY BASELINE
================================================================================

- JWT authentication in an HttpOnly cookie
- No JWT persistence in localStorage
- Role-based authorization on protected server routes
- Helmet security headers
- Restricted CORS with credentials
- JSON and URL-encoded request limits
- Global and authentication rate limiting
- Cookie-authenticated mutation origin protection
- Audit middleware for sensitive requests
- Production environment validation
- Server-side payment verification
- Generic production error responses

VALIDATION
================================================================================

Backend validation commands:
  npm run typecheck
  npm run build

Frontend validation commands:
  npm run lint
  npm run build

GitHub Actions also runs high-severity dependency audits. The dependency audit
remains a separate hardening item where vulnerable packages must be upgraded
without introducing application-breaking major-version changes.

================================================================================
END-TO-END LIMITATIONS
================================================================================

Repository inspection and code validation cannot prove live production behavior
for MongoDB, SMTP, payment providers, deployed HTTPS cookies/CORS, or external
frontend/backend connectivity without the corresponding configured services.

Those checks belong to deployment/runtime verification and security hardening.
